# Visual Assets Plan

## Purpose

Visual assets must make Hostel Premium feel trustworthy, premium, and distinct. They should support real product meaning, not decorate the app randomly.

## Needed Asset Types

```text
hostel room photos
hostel exterior photos
student lifestyle images used sparingly
area/location visuals
map/location illustrations
premium empty states
failed/error states
permission states
verification/trust visuals
owner/admin dashboard state visuals
hero/search background visuals
```

## 3D Visual Direction

3D assets are allowed for:

```text
location permission prompts
empty search results
failed/error states
no saved hostels
no booking requests
verification explanation
onboarding moments
map/location discovery
owner dashboard empty states
```

Why:

```text
Good 3D assets can make state screens feel premium, friendly, and intentional. They are useful when the screen has little real content, such as permission, error, failed, or empty states.
```

Rules:

```text
Use 3D assets as supporting visuals, not as the whole brand.
Keep the style consistent across the app.
Use Hostel Premium colors where possible.
Avoid childish mascot-style dependency.
Avoid random unrelated 3D objects.
Do not use 3D assets for actual hostel rooms or listings unless clearly illustrative.
Real hostel listings need real/approved hostel photos.
```

## State Screen Patterns

### Location Permission / Location Context

Use 3D visual:

```text
map sheet + large location pin + Hostel Premium accent colors
```

Copy:

```text
Choose your UCC area to find nearby hostels.
```

Actions:

```text
Select area manually
Use my location later if location permission is implemented
```

Rule:

```text
Do not request GPS permission in MVP unless the feature is actually implemented and needed.
```

### Empty Search Results

Use 3D visual:

```text
search icon/map pin/empty room card composition
```

Copy:

```text
No hostels match these filters yet.
```

Actions:

```text
Clear filters
Browse all UCC hostels
Notify me when more listings are added
```

### Failed/Error State

Use 3D visual:

```text
broken map pin, warning card, or calm support icon
```

Copy:

```text
We could not load hostels right now.
```

Actions:

```text
Try again
Go back to search
```

Rule:

```text
Keep error visuals calm. Do not make failure feel playful or unserious.
```

### No Saved Hostels

Use 3D visual:

```text
empty saved folder or heart/search composition
```

Copy:

```text
Save hostels you want to compare later.
```

Action:

```text
Browse UCC hostels
```

### No Booking Requests

Use 3D visual:

```text
message/enquiry card with hostel key or room card
```

Copy:

```text
Your hostel enquiries will appear here.
```

Action:

```text
Find hostels
```

### Verification Explanation

Use 3D visual:

```text
shield/check/map/room-photo composition
```

Copy:

```text
Trust labels show how much of a listing has been reviewed.
```

Action:

```text
Learn what each label means
```

## Real Hostel Image Rules

Use:

```text
clear room photos
clear exterior photos
bright natural lighting
uncropped bed/room context
amenity photos where useful
area/location context images
```

Avoid:

```text
dark images
blurred images
overly cropped photos
stock images pretending to be real hostels
AI-generated hostel rooms for actual listings
unverified photos marked as confirmed
```

## Asset QA Checklist

Before accepting an asset:

```text
1. Does it fit Hostel Premium's warm, trustworthy style?
2. Is the license safe for commercial use?
3. Is attribution required?
4. Does it match our colors or can it be adjusted?
5. Is it useful for the state/page?
6. Does it avoid childish or random AI style?
7. Is it optimized for web performance?
8. Does it have alt text or meaningful fallback?
```
