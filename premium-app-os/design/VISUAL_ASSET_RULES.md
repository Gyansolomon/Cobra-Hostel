# Visual Asset Rules

Premium apps often use custom visuals, not just UI components.

## Asset Types

- onboarding artwork
- lifestyle images
- abstract hero graphics
- empty state illustrations
- branded backgrounds
- gradient shapes
- decorative patterns
- feature graphics

## Formula

```text
Subject + Brand Background + Decorative Elements + Premium Color Treatment
```

## Rules

- Create a consistent art direction.
- Use one visual system across onboarding and empty states.
- Use controlled brand colors.
- Leave negative space for text.
- Use mobile-friendly portrait composition.
- Use depth, soft shadows, and subtle gradients.
- Avoid clutter.
- Avoid random unrelated AI art.
- Do not copy another app exactly.

## Prompt Template

```text
Create a branded visual asset system for [APP_TYPE].

The app needs artwork that combines:
- [subject/lifestyle scene]
- branded abstract backgrounds
- soft gradients
- rounded shapes
- subtle depth
- elegant decorative patterns
- mobile-friendly composition

Do not generate random unrelated images.

Create a consistent art direction:
1. subject style
2. background design language
3. color family
4. decorative shape system
5. lighting/mood
6. cropping rules
7. negative space rules
8. how to create a multi-screen series

The result should feel premium, modern, trustworthy, and original.
```
