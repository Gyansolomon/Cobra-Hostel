# Premium Layout Rules

## Core Rule

A premium app is not only about beautiful components. The page composition must feel intentional.

```text
Components make the UI look nice.
Layout makes the product feel premium.
```

## Premium Page Formula

```text
Page = Shell + Header + Primary Zone + Secondary Zone + Detail Zone + Action Zone
```

## Rule 1: One Dominant Focus

Every screen should have one main thing the user understands immediately.

Bad:

```text
Everything is the same size.
All sections fight for attention.
```

Good:

```text
One section dominates.
Other sections support it.
```

## Rule 2: Avoid Equal Card Grids Everywhere

Bad:

```text
[Card] [Card] [Card]
[Card] [Card] [Card]
```

Better:

```text
[Large primary panel        ] [Small support panel]
[Medium content list        ] [Stacked mini cards]
```

## Rule 3: Plan Before Coding

Before implementing a screen, define:

1. screen goal
2. primary action
3. content priority
4. layout pattern
5. component list
6. loading state
7. empty state
8. error state
9. mobile behavior
10. motion behavior

## Common Layout Patterns

### Mobile Discovery App

```text
Top context/search area
Featured/hero card
Quick filters
Content feed
Bottom navigation
```

### Detail Page

```text
Hero image
Title and metadata
Primary action
Key info cards
Description
Gallery/details
Sticky bottom action
```

### Dashboard

```text
Header
KPI row
Main chart/table
Right status panel
Recent activity
```

### AI Workspace

```text
Sidebar/library
Main workspace
Right context panel
Bottom composer
```
