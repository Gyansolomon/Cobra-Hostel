# Design Audit Checklist

Use this before calling a UI complete.

## Layout

- The screen has one dominant focus.
- Important actions are visually obvious.
- The layout is not only a vertical stack of same-sized cards.
- Desktop, tablet, and mobile spacing are intentional.
- Empty, loading, error, and success states exist.

## Visual System

- Colors match `DESIGN.md`.
- Typography uses the documented scale.
- Spacing follows the spacing system.
- Components are reused instead of recreated randomly.
- Visual assets match the product and audience.

## Motion

- Motion is subtle, fast, and useful.
- Transitions explain state change.
- Animations avoid layout thrashing.
- Reduced-motion users are respected.

## Accessibility

- Text contrast is readable.
- Interactive controls have clear labels.
- Keyboard focus is visible.
- Forms show helpful validation errors.

## Final Pass

- The screen feels premium, calm, and usable.
- Nothing looks generic, crowded, or randomly generated.
- The implementation matches the planned product goal.
