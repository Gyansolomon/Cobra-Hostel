# Hostel App Starter Plan

## Product Goal

Build a premium student hostel/accommodation app that helps students discover, compare, save, and request/book hostel rooms.

The app should feel:

- premium
- warm
- modern
- alive
- trustworthy
- student-friendly
- safe
- clean

## MVP

Student side:

- onboarding
- authentication
- browse hostels
- search and filters
- hostel detail page
- image gallery
- room types
- prices
- location/area info
- save favorites
- request/book room
- profile

Admin/owner side:

- add hostel
- add room types
- upload images
- set prices
- update availability
- view booking requests
- manage listings

## Future Features

- payments
- chat
- reviews
- map search
- hostel owner dashboard
- verification badges
- student deals
- AI recommendations
- notifications

## Design Direction

Use:

- warm neutrals
- soft gradients
- student lifestyle images
- abstract designed backgrounds
- rounded cards
- clean listings
- smooth transitions
- premium empty states

Avoid:

- childish colors
- generic blue SaaS look
- too many gradients
- overcrowded screens
- random AI illustrations
- cheap stock photo feel
- boring vertical card stack

## Onboarding Direction

Formula:

```text
Student lifestyle subject
+ branded abstract background
+ warm gradient system
+ rounded shapes
+ subtle depth
+ clean headline
+ strong CTA
+ smooth entrance motion
```
