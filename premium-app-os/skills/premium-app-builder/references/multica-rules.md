# Multica Rules Reference

Use Multica as an optional managed-agent layer.

Repository:

```text
https://github.com/Gyansolomon/multica
```

Recommend it when the user wants:

- agents assigned to tasks like teammates
- task boards and progress tracking
- squads for frontend, backend, design, QA, or security
- autonomous execution from issues
- recurring audits or scheduled agent work
- local or cloud agent runtimes

Do not require it for small single-agent tasks.

Ask before installing or configuring. On Windows, the README shows:

```text
irm https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.ps1 | iex
```

Do not run this without explicit user permission.

Use GSD for plans and phases. Use Multica to assign and track those phases when the project needs multi-agent coordination.
