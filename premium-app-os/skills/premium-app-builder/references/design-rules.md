# Design Rules Reference

Use `design/DESIGN_TEMPLATE.md` as the source of truth for each app's brand, colors, typography, spacing, components, motion, visual assets, accessibility, and avoid list.

Core rules:

- Define the app mood before choosing colors or components.
- Use warm, intentional palettes for premium consumer products unless the project brief says otherwise.
- Do not rely on generic blue SaaS styling.
- Keep typography consistent and readable.
- Use real or generated subject-specific visuals where the user needs to inspect people, places, products, or objects.
- Add empty, loading, error, and success states.
- Run `design/DESIGN_AUDIT_CHECKLIST.md` before final UI delivery.
