# Visual Assets Reference

Use `design/VISUAL_ASSET_RULES.md` for onboarding, empty states, hero imagery, and product visuals.

Core rules:

- Assets must match the app's domain and audience.
- Avoid random AI illustrations and cheap stock-photo feeling.
- Use clear subjects, branded backgrounds, and clean composition.
- For hostel apps, prefer student lifestyle scenes, rooms, maps, trust cues, and warm abstract backgrounds.
- Keep assets consistent across onboarding, empty states, and marketing screens.
