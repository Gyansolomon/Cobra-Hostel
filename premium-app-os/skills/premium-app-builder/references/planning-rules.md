# Planning Rules Reference

Use these files before building any serious app:

```text
planning/PLANNING_WORKFLOW_CHECKLIST.md
planning/QUESTION_BANK.md
planning/REFERENCE_GATHERING_RULES.md
planning/PAGE_PLANNING_RULES.md
planning/COMPONENT_AND_TOOL_SELECTION.md
planning/PAID_TOOLS_AND_MCP_RULES.md
planning/GSD_CORE_WORKFLOW.md
planning/MULTICA_WORKFLOW.md
planning/KARPATHY_AGENT_GUIDELINES.md
```

Core rule:

```text
Discovery -> references -> page plans -> component/tool choices -> paid/MCP disclosure -> roadmap -> phase plan -> execution -> verification -> ship
```

Do not skip:

- user goals
- success criteria
- questions that change the plan
- references for important screens
- page-level state planning
- component/tool cost disclosure
- MCP/setup permission
- verification evidence
