# Layout Rules Reference

Use `design/LAYOUT_RULES.md` and `design/SPACING_RULES.md` before coding screens.

Core rules:

- Create a layout plan before implementation.
- Give each page one dominant content area.
- Avoid repeating equal card grids across every screen.
- Use clear hierarchy: primary action, secondary action, supporting information.
- Use stable responsive constraints so content does not overlap or clip.
- Mobile screens should feel designed, not compressed from desktop.
