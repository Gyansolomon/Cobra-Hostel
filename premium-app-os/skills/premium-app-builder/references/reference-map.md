# Reference Map

Use `global/REFERENCE_MAP.md` for the complete skills, tools, components, backend services, security tools, monitoring tools, and infrastructure reference.

Use `global/INSTALLABLE_SKILLS_PACK.md` for safe install order and install commands.

Core rule:

```text
Installed skills can be invoked.
External tools must be checked or installed with permission.
Component sources may be free or paid.
Backend services require cost, security, and setup review.
```

Before recommending any item, answer:

```text
What is it?
Is it installed?
Is it free or paid?
Does it require login/setup?
What is the fallback?
```
